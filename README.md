# Live Markdown Editor

A Nuxt (Vite) app with a split-pane live markdown editor: write on the left, preview on the right.

**Live site:** https://xmissj.github.io/live-markdown-editor/

## Setup

```bash
npm install
```

## Development

Start the dev server on `http://localhost:3000`:

```bash
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## GitHub Pages

Pushes to `main` deploy via GitHub Actions (`.github/workflows/deploy.yml`).

In the repo on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
